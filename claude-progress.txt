**Technical Background - Freezed Explained**:
Freezed is a Dart code generation library that automatically generates immutable model classes:
- **Immutability**: Prevents accidental state mutations
- **Equality**: Auto-generates `==` and `hashCode` for value comparison
- **Copy-With**: Generates `.copyWith()` for safe object modification
- **JSON Serialization**: Auto-generates `fromJson()` and `toJson()` methods
- **Pattern Matching**: Enables powerful union types
- **Build Outputs**: Creates `.freezed.dart` (immutability) and `.g.dart` (JSON serialization)

Used in this project because Riverpod state management relies on value equality, and models must be immutable for safe reactive updates.

**Implementation Steps**:

1. **Created TrainerModel** (`lib/features/auth/data/models/trainer_model.dart`):
```dart
@freezed
class TrainerModel with _$TrainerModel implements Trainer {
  const factory TrainerModel({
    required String email,
    required String name,
    String? photoUrl,
  }) = _TrainerModel;

  factory TrainerModel.fromJson(Map<String, dynamic> json) =>
      _$TrainerModelFromJson(json);
}
```

2. **Created ClientModel** (`lib/features/auth/data/models/client_model.dart`):
```dart
@freezed
class ClientModel with _$ClientModel implements Client {
  const factory ClientModel({
    required String email,
    required String name,
    required int trainerId,
  }) = _ClientModel;

  factory ClientModel.fromJson(Map<String, dynamic> json) =>
      _$ClientModelFromJson(json);
}
```

3. **Fixed Domain Entities**:
   - Removed `Equatable` from `Trainer` and `Client` entities
   - Reason: Freezed generates its own equality implementation - having entities also extend Equatable creates conflicting abstract member requirements
   - Entities now serve as pure data holder interfaces with fields only
   - Freezed models implement these interfaces and provide equality via code generation
